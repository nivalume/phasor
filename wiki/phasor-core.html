phasor-core

整个引擎共用的地基 crate：浮点容差、零分配广播、列主序矩阵、多层列标签、不变量错误。 Cargo.toml 的 [dependencies] 是空的，只依赖 Rust 标准库。 下游数字是否可信，取决于这里的四件事没有被绕开。

0外部 crate 依赖。arrow、polars、pyo3 都不进这一层
5模块：math、flex、matrix、columns、error
10 + 110 个 crate 在 src 里直接使用；phasor-model 只在 Cargo.toml 里声明

点一个节点

模块说明它被谁使用；crate 说明它拿 phasor-core 的哪一部分去做什么。

crate 内部

五个模块之间只有一条依赖方向：flex、matrix、columns 在长度或标签不合法时返回 Error。math 不依赖它们。

内部依赖：校验失败统一落成 Error，比较与存储互不引用

FlexLen、LevelWidth、UnknownLevel、Broadcast、Invariant 都是同一个手写枚举，故意不用 thiserror，这样地基 crate 保持零依赖。

五个模块做什么

math

所有金额比较的唯一入口。is_close 按 PEP 485（相对 1e-9、绝对 1e-12），但 NaN 与 ±inf 永远不 close，包括 inf 对 inf——因为 +inf 是活哨兵（size 表示全部可下，price 表示用收盘价）。买入是否付得起用 is_close_or_less，不用 <=。余额更新用 add，相消的和吸附成精确的 0.0，避免 1e-17 的灰尘把已平仓位留成“还开着”。

flex

FlexArray 让标量、逐列、逐行、整矩阵、以及 MappedColumns（column_map）共用一次内联 get(row, col)，不把参数物化成 T×C。100k×2000 的一张 f64 矩阵是 1.6 GB；扫描里十几个参数如果都物化，内存先被参数吃掉。标量分支不访问内存。varies_by_row() 让循环把逐列常量提出去。

matrix

列主序 Matrix { data, n_rows, n_cols }，(row, col) 落在 data[col * n_rows + row]。column(c) 是零拷贝的连续切片：模拟扫一列、因子按一列求值、线程拥有一段列，都依赖这一点。NumPy 默认行主序，跨进 Rust 的数组必须是 Fortran 序，否则会把时间和品种轴对调。

columns

模拟器只看见 n_cols 条独立序列。参数、品种、因子都折进同一条列轴之后，Columns 是把结果归因回去的唯一机制。Level::repeat 做参数（一块参数的列连续），Level::tile 做品种，于是 col = param_idx * n_symbols + symbol_idx。这是构造约定，运行时不检查；group_indices 按标签分组，供分析层 group_by 使用。浮点标签按位模式比较，NaN 等于自身。

error

Error 只表示不变量被破坏：形状广播失败、FlexArray 长度不对、列标签层级不存在或宽度不一致、以及模拟器发现的数值不变量（例如负现金）。拒单一张订单不是 Err，而是带状态码的正常返回。变体手写 Display，信息里带上出错的名字和实际/期望长度。

类图

公开类型就这些。math 没有自己的类型，只有函数和两个常量。 实心菱形是拥有；虚线是依赖，箭头指向被返回或被校验成的 Error。 字段前面的 - 表示私有，+ 表示公开。

数值：广播、矩阵、容差。FlexArray 与 Matrix 不互相持有，只共用列主序下标

核心类型

成员与源码一致。拒单不是这些类型里的任何一种值。

math

math.rs · 没有类型。两个常量，六个公开函数。比较的是 f64，不返回 Error

函数含义
REL_TOL / ABS_TOL默认相对容差 1e-9，绝对容差 1e-12。is_close 使用这一对。
is_close(a, b)NaN 与任何值都不 close，包括 NaN 自己。±inf 也不 close，包括 inf 对 inf。+inf 是规模和价格的活哨兵。
is_close_tol(a, b, rel, abs)同一套判断，容差由调用方传入。有限且位模式相同的值走 a == b 短路。
is_close_or_less(a, b)is_close(a, b) || a < b。买入是否付得起用这个，不用 <=。
is_less(a, b)不 close 且 a < b。容差内的两个值既不小于也不大于。
is_addition_zero(a, b)异号时比较绝对值是否 close，避免两个大数相消后相对误差失真。同号时看和是否 close 于 0。
add(a, b)相消则返回精确的 0.0，否则返回 a + b。现金、持仓、负债、自由现金的累加走这里。

FlexArray<'a, T>

flex.rs · 枚举 · 借用原切片，不把参数物化成 T×C

成员含义
Scalar(T)scalar(value) 不检查长度。get 不访问切片，处处返回同一个值。
PerColumn(&'a [T])长度必须等于 n_cols，否则 FlexLen { kind: "per-column" }。沿行不变，varies_by_row() 为 false。
PerRow(&'a [T])长度必须等于 n_rows，否则 FlexLen { kind: "per-row" }。沿列不变。
MappedColumns字段 data、n_rows、columns。读 data[columns[col] * n_rows + row]。mapped 要求 data 恰好是 n_rows × source_cols，columns 非空且每个下标小于 source_cols，否则 Invariant。
Full { data, n_rows }读 data[col * n_rows + row]。长度必须是 n_rows * n_cols，否则 FlexLen { kind: "full" }。
get(row, col) -> TT: Copy。下标超出底层存储会 panic；checked 构造保证，在声明的形状里面这是不可达的。
varies_by_row() -> boolPerRow、Full、MappedColumns 为 true。为 false 时，调用方可以把读提到内层循环外面。

Matrix

matrix.rs · 结构体 · 拥有一块列主序 Vec<f64>。字段私有

成员含义
filled / zeros按 n_rows * n_cols 分配。zeros 是 filled(0.0)。
from_column_majordata.len() != n_rows * n_cols 时返回 FlexLen { kind: "matrix" }。
column / column_mut第 col 列是连续切片 data[col * n_rows .. (col + 1) * n_rows]。col >= n_cols 时 panic。
get(row, col) -> f64同一下标公式。任一轴越界 panic。
as_slice / into_vec整块列主序缓冲。into_vec 把所有权交出去。
map_columns对每一列调用 Fn(&[f64]) -> f64，得到长度 n_cols 的向量。

Label、Level、Columns

columns.rs · 标签是标识，不是测量。Float 用位模式比较，所以 NaN 等于自身，0.0 不等于 -0.0

类型成员含义
LabelInt(i64) · Float(f64) · Str(Arc<str>) · Bool(bool)Label::str 从任意 AsRef<str> 构建。From 接受 i64、usize（转成 i64）、f64、bool、&str。Eq 和 Hash 对 Float 使用 to_bits。
Levelname · labelsnew 不检查长度。repeat 把每个值连续重复 times 次，用来做参数层。tile 把整段序列重复 times 次，用来做品种层。
Columnslevels · n_colsunlabelled(n) 没有层级。new 在 levels 为空时得到 unlabelled(0)；否则每一层的长度必须等于第一层，不一致则 LevelWidth。
Columns::levelname -> &Level找不到名字时 UnknownLevel，available 是现有层级名，逗号分隔。
Columns::label(col, level) -> &Label先做 level 查找。col >= n_cols 时 panic。
group_indiceslevel -> Vec<(Label, Vec<usize>)>按该层标签分组，顺序是标签第一次出现的顺序。找不到层级则 UnknownLevel。分析层的 group_by 用它。
describecol -> String没有层级时返回 col{n}。有层级时拼成 name=label, …；列号越界会 panic。

Error 与 Result

error.rs · pub use error::{Error, Result} 在 crate 根。实现 Display 和 std::error::Error

变体谁返回字段

UnknownLevelColumns::level、label、group_indicesname 是查找的名字，available 是已有层级

InvariantFlexArray::mapped；其余 crate 用它表示不可能的数值或列号一条 String。mapped 的原文是 column_map 必须非空，并且下标落在形状正确的源矩阵里

两条不能绕开的规则

工作区 lint 把 clippy::float_cmp 和 unsafe_code 设为 deny。金融比较必须走 phasor_core::math。在 math 内部对 a == b 的短路是 isclose 契约的一部分，用局部 #[expect] 标明理由。 
col = param_idx * n_symbols + symbol_idx
data[col * n_rows + row]          // 列主序，一列一段 &[f64]
is_close(inf, inf) == false       // 哨兵不能被容差吞掉
add(a, -a) == 0.0                 // 当两者幅度 is_close

crate用到的模块用来做什么

phasor 把 Columns、FlexArray、Matrix、Error 放进 prelude 再导出。phasor-py 把 Error 转成 PyErr（array.rs 的 to_py_err）。
